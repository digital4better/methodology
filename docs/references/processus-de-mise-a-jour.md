# Processus de mise à jour

## En bref

Une méthode utile dans la durée doit assumer ses révisions. Cette page décrit comment les évolutions de données, de sources et de conventions méthodologiques doivent être tracées et intégrées.

## Ce qui peut évoluer

Les révisions peuvent concerner :

- les jeux de données et facteurs ;
- les valeurs par défaut ;
- les règles d’allocation ;
- les conventions de modélisation ;
- le périmètre de certains cas d’usage.

## Principe de gouvernance

Chaque mise à jour significative doit documenter :

- ce qui change ;
- pourquoi cela change ;
- quelles pages sont touchées ;
- quelle version du référentiel de données est mobilisée ;
- quel impact la révision peut avoir sur les résultats.

## Fréquence cible

La fréquence de révision peut varier selon les sujets, mais la logique cible est :

- revue régulière des données de fond ;
- mise à jour à l’événement pour les changements méthodologiques majeurs ;
- historisation visible des décisions.

## Hypothèses et limites

- La gouvernance précise peut encore évoluer.
- Cette page pose le cadre de mise à jour avant outillage éventuel.
