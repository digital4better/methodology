# Vue d’ensemble du matériel

## En bref

La section `Matériel` organise le corpus physique de la méthode selon une progression simple :

- matériaux ;
- composants ;
- équipements ;
- réseaux et infrastructures.

Cette progression permet de comprendre d’où viennent les impacts avant de les recomposer dans un équipement, une infrastructure ou un cas d’usage.

## Pourquoi partir du matériel

Les impacts du numérique sont fortement déterminés par des objets physiques :

- extraction et transformation de matières ;
- fabrication de composants ;
- assemblage en équipements ;
- usage dans des réseaux et centres de données.

Parler de logiciel ou de service sans relier ces couches à leurs supports matériels conduit souvent à des raisonnements incomplets.

## Comment lire cette section

- `Matériaux` sert de couche amont explicative.
- `Composants` présente les composants techniques les plus structurants.
- `Équipements` montre comment ces composants sont regroupés en objets utilisables.
- `Réseau et infrastructure` traite les couches support partagées.

## Hypothèses et limites

- Le niveau `Matériaux` n’est pas encore traité comme une couche de calcul complètement autonome dans cette itération.
- Toutes les sections de `Matériel` n’ont pas aujourd’hui le même niveau de couverture dans les référentiels de données.
